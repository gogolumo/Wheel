# Wheel — Liquid Glass Hero

This file pins the approved visual reference for the Wheel Liquid Glass direction.

![Wheel Liquid Glass hero](https://d2ol7oe51mr4n9.cloudfront.net/user_3K6hC4CbR5JZ72OzltHJ5TIZGMp/972166f0-49d6-4f29-8db0-ca99efb04763.png)

## Visual contract

Treat the image above as the primary visual reference. Future iterations should preserve its composition, layout, proportions, lighting, material treatment, interface placement, app placement, camera framing, and overall atmosphere unless an explicit design change is approved.

### Fixed composition

- 16:9 full-screen macOS desktop.
- Cinematic alpine lake wallpaper with warm sunrise from the left and cool mountain shadows.
- Thin macOS-style menu bar at the top.
- Upper-left “Wheel” product title with the tagline “Your apps, in context. Right where you need them.”
- Large circular Liquid Glass Wheel in the center.
- Seven radial app sectors around a circular center hub.
- Safari selected at the top.
- Finder upper-left.
- Mail upper-right.
- WhatsApp lower-left.
- Notion lower-right.
- Figma bottom-left.
- Visual Studio Code bottom-right.
- Floating Safari context panel to the right.
- Translucent macOS-style Dock centered at the bottom.

### Liquid Glass rules

- Glass is a functional interface layer, not decoration.
- Preserve underlying wallpaper visibility through translucent surfaces.
- Use refined blur, adaptive luminosity, subtle chromatic refraction, soft cyan/lilac edge dispersion, white specular highlights, rounded geometry, layered transparency, and restrained optical distortion.
- Keep text and controls highly legible.
- Avoid generic glassmorphism, heavy bloom, opaque panels, thick borders, noisy gradients, cyberpunk styling, and decorative clutter.

### Selection state

Safari remains the selected context in this hero:
- slightly protruding sector,
- subtly larger geometry,
- brighter cool-blue edge illumination,
- stronger refraction,
- premium rather than neon emphasis.

### Rendering target

The target is a flagship-quality macOS product reveal visual: calm, premium, spatial, trustworthy, polished, and believable as a native OS-level interaction.

## Regeneration prompt

Use the attached/linked reference image as the PRIMARY visual reference.

Recreate the image as closely as possible in composition, layout, proportions, lighting, material treatment, interface placement, spacing, camera framing, and overall atmosphere.

This is NOT a loose interpretation and NOT a redesign.

The goal is to reproduce the reference visual almost 1:1 while keeping the image crisp, premium, believable, and production-quality.

Do not reinterpret the composition, rearrange the apps, remove the Safari panel, remove the Dock, replace the mountain lake wallpaper, simplify the Wheel into a generic launcher, add extra UI, add people or device frames, change the central circular structure, use cyberpunk styling, use excessive bloom, make the interface opaque, use thick borders, or exaggerate glass distortion.

Reference priority:
1. composition
2. Wheel geometry
3. spatial proportions
4. glass treatment
5. app placement
6. landscape lighting
7. typography placement

Do not sacrifice reference fidelity for artistic experimentation.
