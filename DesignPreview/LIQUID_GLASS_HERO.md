# Wheel — Liquid Glass Hero

This document is the canonical visual reference for the current Wheel Liquid Glass direction.

![Wheel Liquid Glass hero](https://d2ol7oe51mr4n9.cloudfront.net/user_3K6hC4CbR5JZ72OzltHJ5TIZGMp/2c1f85e0-a74d-4fe5-b7df-1b97aa2f14e2.png)

> **Primary reference rule:** preserve this image's composition, geometry, spatial proportions, lighting, app placement, Safari panel placement, Dock placement, typography placement, and Liquid Glass treatment unless an explicit design change is approved.

## Visual contract

- 16:9 full-screen macOS desktop composition.
- Cinematic alpine lake wallpaper with warm sunrise from the left and cool mountain shadows.
- Thin macOS-style menu bar.
- Upper-left `Wheel` title with:
  - `Your apps, in context.`
  - `Right where you need them.`
- Large circular Liquid Glass Wheel centered in the composition.
- Seven radial sectors around a circular center hub.
- Safari selected at top.
- Finder upper-left.
- Mail upper-right.
- WhatsApp lower-left.
- Notion lower-right.
- Figma bottom-left.
- Visual Studio Code bottom-right.
- Tall Safari context panel to the right.
- Translucent macOS-style Dock centered at the bottom.

## Liquid Glass rules

- Treat glass as a functional navigation/interface layer, not decorative frosting.
- Preserve the wallpaper through translucent surfaces.
- Use refined blur, adaptive luminosity, subtle chromatic refraction, cyan/lilac edge dispersion, white specular highlights, layered transparency, and restrained optical distortion.
- Selection must remain legible through depth, border light, geometry, and contrast — not neon.
- Avoid generic glassmorphism, heavy bloom, opaque cards, thick borders, cyberpunk styling, noisy gradients, and clutter.

## Master regeneration prompt

Use the supplied reference image as the PRIMARY visual reference.

Recreate it as closely as possible in composition, layout, proportions, lighting, material treatment, interface placement, spacing, camera framing, and overall atmosphere.

This is NOT a loose interpretation and NOT a redesign.

The goal is to reproduce the reference visual almost 1:1 while keeping the image crisp, premium, believable, and production-quality.

### Project

Wheel — a native macOS context-navigation utility.

### Canvas

16:9 widescreen. Premium keynote-style product hero image. Full-screen macOS desktop composition.

### Background

Use a cinematic mountain lake landscape almost identical in feeling and placement to the reference:

- large calm alpine lake
- rocky mountain ranges surrounding the lake
- snow or light haze on distant peaks
- sunrise / golden-hour light coming from the left side
- warm sun near the left horizon
- cool blue mountain shadows
- subtle atmospheric fog
- realistic reflections in the water
- dark rocky foreground along the lower left and lower right edges

The wallpaper must remain visible through the translucent interface. Do not replace it with an abstract gradient.

### macOS menu bar

Place a very thin native macOS-style menu bar across the very top.

Top-left:
- Apple icon
- Finder
- File
- Edit
- View
- Go
- Window
- Help

Top-right:
- subtle system icons
- display/control icon
- Wi-Fi
- search
- date and time

Keep it extremely subtle and white.

### Left headline

Upper-left:

**Wheel**

Below:

**Your apps, in context.**  
**Right where you need them.**

Use elegant thin native macOS-like typography, spacious and understated, directly over the wallpaper.

### Central Wheel

The main Wheel interface dominates the center and occupies roughly 40–45% of image width.

Use:
- large translucent circular glass shell
- 7 radial application sectors
- circular center hub
- clear sector separation
- rounded organic wedge geometry
- transparent Liquid Glass
- refined edge highlights
- subtle refraction
- faint spectral reflections
- soft internal shadows
- soft external glow
- polished physical-glass coherence
- wallpaper visible through the material

### Center hub

Large circular glass center with the text:

**Wheel**

Use deeper blur than the outer sectors, slight darkening, glossy edge, restrained blue/cyan/lilac iridescent rim, optical depth, and soft shadow.

### Exact app positions

- TOP — Safari
- UPPER LEFT — Finder
- UPPER RIGHT — Mail
- LEFT / LOWER LEFT — WhatsApp
- RIGHT / LOWER RIGHT — Notion
- BOTTOM LEFT — Figma
- BOTTOM RIGHT — Visual Studio Code

Each sector contains one recognizable app icon and its name, centered and consistently sized.

### Selected Safari state

Safari remains selected. Its top sector:
- subtly protrudes outward
- is marginally larger
- has brighter cool-blue edge illumination
- has slightly stronger glass refraction
- reads as selected without excessive neon

### Right Safari context panel

Place a tall rounded Liquid Glass panel to the right of Wheel at approximately the same vertical height, about 20–23% of image width.

Use:
- translucent graphite / blue-gray tint
- subtle glass blur
- very thin white border
- rounded corners
- soft drop shadow
- wallpaper visible through panel

Header:
- Safari icon
- Safari
- `Browse · Research · Create`
- small circular ellipsis button at top-right

### Safari preview

Include a mini Safari browser window using the same mountain-lake visual. Include traffic-light window controls, browser toolbar, centered address/search field, and a clean scenic preview.

### Safari action list

- New Window — ⌘ N
- New Private Window — ⇧ ⌘ N
- Reopen Last Tab — ⇧ ⌘ T
- Show All Windows

Use subtle monochrome icons, right-aligned shortcuts, thin dividers, and native macOS visual language.

### Dock

Centered translucent macOS-style Dock along the bottom, approximately:

Finder → Safari → Mail → WhatsApp → Figma → Visual Studio Code → Notion → divider → Trash

Use transparent frosted Liquid Glass, rounded capsule geometry, subtle blur, and soft shadow. Do not oversize it.

### Material and lighting

Use realistic translucent glass, sophisticated background blur, adaptive luminosity, subtle chromatic refraction, soft cyan/lilac edge dispersion, white specular highlights, polished rounded surfaces, layered transparency, and restrained optical distortion.

Lighting:
- warm sunrise from left
- cool white / pale-blue UI highlights
- warmer reflections on left-facing glass
- cooler reflections on right-facing glass

The interface must feel integrated into the environment rather than pasted on top.

### Color palette

Primary:
- frosted white
- silver
- soft graphite
- cool blue-gray
- transparent glass

Accent:
- restrained cyan
- pale blue
- tiny lilac spectral reflections

Environment:
- warm peach/gold
- cool alpine blue

Avoid strong saturated neon.

### Typography

Use thin, precise, highly legible macOS-like sans-serif typography.

### Avoid

Do not:
- reinterpret the composition
- rearrange apps
- remove the Safari panel
- remove the Dock
- replace the mountain lake wallpaper
- simplify Wheel into a generic launcher
- add extra UI
- add people
- add a MacBook/device frame
- turn it into a website mockup
- change the central circular structure
- use cyberpunk styling
- use excessive bloom
- use a dark-black background
- use opaque panels
- use thick borders
- exaggerate glass distortion
